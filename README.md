# Where's Waldo: File Exercises

This repository contains a data file (census-first-names.txt) and three Python files. Each of the Python files contains instructions for an exercise that will help you practice working with data files.

# Exercises

You should work on the three exercises in the following order:

1. wheres_waldo.py
2. wheres_name.py
3. copy_top_n.py

Detailed instructions can be found in the comments included in each .py file.
